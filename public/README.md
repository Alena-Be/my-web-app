# Как правильно запустить приложение

> ⚠️ **ВАЖНО:** Не открывайте файл `index.html` двойным кликом в папке. Это вызовет ошибку безопасности в браузере, и функции, требующие связи с сервером (например, регистрация), не будут работать.

Следуйте этой простой инструкции, чтобы запустить все правильно.

---

### Шаг 1: Запустите сервер

1.  Откройте терминал в этом проекте.
2.  Выполните следующую команду:

    ```bash
    node server.js
    ```

3.  Эта команда запускает ваш бэкенд-сервер. **Не закрывайте это окно терминала**, пока работаете с приложением. Вы должны увидеть сообщение о том, что сервер запущен.

---

### Шаг 2: Откройте сайт в браузере

1.  Откройте ваш любимый браузер (Chrome, Firefox, Safari и т.д.).
2.  В адресной строке введите следующий адрес и нажмите Enter:

    ```
    http://localhost:3000
    ```

---

### Шаг 3: Проверьте работу

Теперь ваше приложение полностью готово к работе. Попробуйте зарегистрироваться или использовать другие функции сайта. Все должно работать корректно.
