# SLine — фитнес-студия

## Описание проекта

Сайт фитнес-студии SLine. Пользователи могут просматривать расписание, акции, стоимость и оставлять отзывы. Администратор управляет отзывами, просматривает список пользователей и экспортирует отзывы в Excel.

## Технологии

- HTML, CSS, Bootstrap
- JavaScript (Vanilla)
- Node.js, Express
- PostgreSQL
- express-session, bcrypt (авторизация)
- exceljs (экспорт в Excel)

## Функционал

- Регистрация и авторизация через сессии
- Роли: `user` и `admin`
- Личный кабинет с редактированием профиля
- Отзывы: CRUD (создание, чтение, редактирование, удаление)
- Поиск и фильтрация отзывов
- Пагинация
- Экспорт отзывов в Excel (с фильтром и без)
- Защита админ-страниц (requireAuth, requireAdmin)

## Установка и запуск

1. Клонируйте репозиторий:
   git clone https://github.com/Alena-Be/my-web-app.git

2. Перейдите в папку проекта:
   cd my-web-app

3. Установите зависимости:
   npm install

4. Создайте файл .env в корне проекта с настройками БД.

5. Создайте таблицы в PostgreSQL.

6. Запустите сервер: node server.js

7. Откройте в браузере: http://localhost:3000
